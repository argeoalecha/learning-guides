# SaasFlow

Used by: **[GTM Strategy & Automation guide](../../gtm-strategy-automation/gtm-strategy-automation_learning_guide.html)**

**Not a dataset — a business scenario.** This is a non-technical (business) guide; the "running example" is a case-study company, not a file to download. Every exercise and capstone applies its frameworks, scripts, and templates to this one scenario so you build intuition on a single business instead of context-switching.

## The scenario

A B2B SaaS company selling project-management automation to mid-market operations teams at **$8,400 ACV** (annual contract value).

## How to use it

Exercises across the guide ask you to draft outreach sequences, build lead-scoring models, design enrichment workflows (Clay, Module 4.1), and construct GTM motions — all *for SaasFlow specifically*. Treat SaasFlow as a fixed set of facts (ICP: mid-market ops teams, price point: $8,400 ACV, product: PM automation) and keep every artifact you produce consistent with those facts, the same way the guide's own worked examples do.

If you'd rather practice on your own company's numbers, swap SaasFlow's ACV/ICP for your own at the start and keep them fixed for the rest of the guide — consistency across exercises matters more than which numbers you pick.
