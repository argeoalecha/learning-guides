# FitForge

Used by: **[Hormozi 100M Sales guide](../../hormozi-100m-sales/hormozi-100m-sales_learning_guide.html)**

**Not a dataset — a business scenario.** This is a non-technical (business) guide; the "running example" is a case-study offer, not a file to download. Every exercise and capstone practices the whole sales motion on this one business so frameworks compound instead of resetting each module.

## The scenario

FitForge — a high-ticket **$3,000, 12-week fitness-transformation offer**.

## How to use it

Exercises across the guide ask you to draft call openers, objection-handling scripts, offer stacks, and close sequences — all *for FitForge specifically*, using its $3,000 price point and 12-week delivery window as fixed constraints. Keep every script and framework artifact consistent with those numbers, the same way the guide's own worked examples do.

If you'd rather practice on your own offer, swap FitForge's price/duration for your own at the start and keep them fixed for the rest of the guide — consistency across exercises matters more than which numbers you pick.
