Arrays vs. Series vs. DataFrame

NumPy arrays are typed, fixed-size, and optimized for numeric math. A Pandas Series is a 1D array with a labeled index. A DataFrame is a dictionary of aligned Series — the workhorse of data analysis. Understanding the boundary between them prevents the most common performance mistakes (calling .apply() when a vectorized NumPy operation would be 100× faster).

Vectorized Operations

Loops over DataFrame rows are almost always wrong — they're 100–1000× slower than vectorized operations. NumPy broadcasts element-wise operations across entire arrays in C-speed loops.

prices = df["order_value"].to_numpy()

# Vectorized stats — never loop for these
print(f"Mean:   {np.mean(prices):.2f}")
print(f"Median: {np.median(prices):.2f}")
print(f"Std:    {np.std(prices):.2f}")
print(f"P95:    {np.percentile(prices, 95):.2f}")

# Boolean indexing — vectorized row filter
high_value = df[df["order_value"] > 5000]
print(f"High-value orders: {len(high_value):,}")

# Vectorized string normalization (no loop needed)
df["product_category"] = df["product_category"].str.strip().str.lower()

# .loc for label-based, .iloc for position-based access
metro_express = df.loc[
    (df["region"] == "NCR") & (df["delivery_tier"] == "express"),
    ["order_id", "order_value", "delivery_date"]
]

Measures of Central Tendency & Spread

The mean is sensitive to outliers; use it only when the distribution is roughly symmetric. The median is robust. Mode is for categorical data. Variance and standard deviation measure spread around the mean; IQR measures spread around the median — use IQR when you have outliers.

Five-Number Summary & Distribution Shape

import pandas as pd
import numpy as np
from scipy import stats

df = pd.read_csv("shopflow_orders.csv")

# --- Five-number summary + mean ---
print(df["order_value"].describe())
# min, 25%, 50%, 75%, max — plus count, mean, std

# --- Skewness and kurtosis ---
# Skewness > 0: right tail (common for monetary data)
# Kurtosis > 3 (excess kurtosis > 0): heavier tails than normal
print(f"Skewness: {df['order_value'].skew():.3f}")
print(f"Kurtosis: {df['order_value'].kurt():.3f}")  # excess kurtosis

# --- Mode for categorical columns ---
print(f"Most common category: {df['product_category'].mode()[0]}")

# --- Weighted mean: order value weighted by quantity ---
weighted_mean = np.average(
    df["order_value"].dropna(),
    weights=df.loc[df["order_value"].notna(), "quantity"]
)
print(f"Weighted mean order value: ₱{weighted_mean:,.2f}")

# --- Coefficient of variation (relative spread, unit-free) ---
cv = df["order_value"].std() / df["order_value"].mean()
print(f"CV: {cv:.3f}")  # > 1 means very high dispersion

Testing for Normality

Most statistical tests assume normality. Monetary data is almost always right-skewed — applying a t-test to raw order_value without checking the distribution first is a common mistake. The log transform is the standard fix for right-skewed positive data.

import numpy as np
import pandas as pd
from scipy import stats

df = pd.read_csv("shopflow_orders.csv")
order_values = df["order_value"].dropna()

# --- D'Agostino-Pearson normality test ---
# H0: data is normally distributed
stat, p_value = stats.normaltest(order_values)
print(f"Normality test — p: {p_value:.4e}")   # very small: reject H0

# --- Log-transform to approach normality ---
log_values = np.log1p(order_values)   # log1p = log(1+x), safe for x=0
stat2, p_value2 = stats.normaltest(log_values)
print(f"Log-transformed  — p: {p_value2:.4f}")   # much larger

Fitting & Sampling Distributions

import numpy as np
from scipy import stats

log_values = np.log1p(df["order_value"].dropna())

# --- Fit normal to log-transformed data ---
mu, sigma = stats.norm.fit(log_values)
print(f"Fitted log-normal: μ={mu:.3f}  σ={sigma:.3f}")

# --- Generate synthetic samples from the fitted distribution ---
rng = np.random.default_rng(seed=42)
synthetic = rng.normal(loc=mu, scale=sigma, size=10_000)
synthetic_original_scale = np.expm1(synthetic)  # invert log1p

# --- Bootstrap 95% CI for the median order value ---
bootstrapped_medians = [
    np.median(rng.choice(df["order_value"].dropna().to_numpy(),
                         size=1000, replace=True))
    for _ in range(5000)
]
ci_low, ci_high = np.percentile(bootstrapped_medians, [2.5, 97.5])
print(f"Bootstrap 95% CI for median: [₱{ci_low:.2f}, ₱{ci_high:.2f}]")

The Quality Audit Pattern

Never start cleaning without a full audit first. Jumping straight to .fillna() without understanding which columns are missing, how much, and in what pattern leads to imputation choices that introduce bias. Build a reusable quality_report() function and run it at the start of every project.

import pandas as pd
import numpy as np

df = pd.read_csv("shopflow_orders.csv")

def quality_report(frame: pd.DataFrame) -> pd.DataFrame:
    missing = frame.isnull().sum()
    missing_pct = (missing / len(frame) * 100).round(2)
    return pd.DataFrame({
        "dtype":         frame.dtypes,
        "missing_count": missing,
        "missing_pct":   missing_pct,
        "n_unique":      frame.nunique(),
        "sample_values": [frame[c].dropna().unique()[:3].tolist() for c in frame.columns],
    }).sort_values("missing_pct", ascending=False)

report = quality_report(df)
print(report.to_string())

Module 2.2 — Handling Missing Data

Skip if: You understand MCAR, MAR, and MNAR and can apply KNN imputation from scikit-learn.

Missing Data Mechanisms

MCAR (Missing Completely At Random) — missingness is unrelated to any variable. Safe to drop rows. MAR (Missing At Random) — missingness depends on observed variables (e.g., shipping_fee is missing only for COD orders). Imputation with context is safe. MNAR (Missing Not At Random) — missingness depends on the missing value itself (e.g., very high discounts are redacted). Imputation will introduce bias; flag and document.

Four Imputation Strategies

import pandas as pd
import numpy as np
from sklearn.impute import KNNImputer

df = pd.read_csv("shopflow_orders.csv", parse_dates=["order_date", "delivery_date"])

# --- Strategy 1: Drop rows where the analysis target is missing ---
# Only safe under MCAR assumption and low missing %
df_clean = df.dropna(subset=["order_value"]).copy()
print(f"Rows kept: {len(df_clean):,}  ({len(df_clean)/len(df)*100:.1f}%)")

# --- Strategy 2: Forward-fill for time-ordered, sparse categorical ---
# delivery_status progresses monotonically per order — ffill is appropriate
df_clean = df_clean.sort_values(["order_id", "order_date"])
df_clean["delivery_status"] = (
    df_clean.groupby("order_id")["delivery_status"].ffill()
)

# --- Strategy 3: Median imputation for numeric columns (MAR) ---
# Use transform so the median is computed per group, not globally
df_clean["discount_pct"] = df_clean.groupby("product_category")["discount_pct"] \
    .transform(lambda x: x.fillna(x.median()))

# --- Strategy 4: KNN imputation for correlated numeric features ---
numeric_cols = ["order_value", "quantity", "weight_kg", "shipping_fee"]
imputer = KNNImputer(n_neighbors=5)
df_clean[numeric_cols] = imputer.fit_transform(df_clean[numeric_cols])

print(f"Missing values remaining: {df_clean.isnull().sum().sum()}")

Module 2.3 — Outlier Detection & Treatment

Skip-check (test-out): Detect IQR outliers and Z-score outliers on the same column. Explain why they give different counts.

IQR Fences vs. Z-Score

The IQR method is non-parametric — it makes no assumption about the distribution. Z-score assumes normality. For right-skewed data like order_value, Z-score will miss many outliers while IQR will catch them. Use IQR as the default for business data.

import pandas as pd
import numpy as np
from scipy import stats

df = pd.read_csv("shopflow_orders.csv")
col = df["order_value"].dropna()

# --- IQR fences ---
Q1, Q3 = col.quantile(0.25), col.quantile(0.75)
IQR = Q3 - Q1
lower_fence = Q1 - 1.5 * IQR
upper_fence = Q3 + 1.5 * IQR
iqr_mask = (df["order_value"] < lower_fence) | (df["order_value"] > upper_fence)
print(f"IQR outliers: {iqr_mask.sum()} ({iqr_mask.sum()/len(df)*100:.2f}%)")
print(f"  Lower fence: ₱{lower_fence:,.2f}  Upper fence: ₱{upper_fence:,.2f}")

# --- Z-score (assumes near-normal) ---
z = np.abs(stats.zscore(col))
z_mask = z > 3
print(f"Z-score outliers (|z| > 3): {z_mask.sum()}")

# --- Winsorizing: cap at percentile bounds (preferred over dropping) ---
p01 = df["order_value"].quantile(0.01)
p99 = df["order_value"].quantile(0.99)
df["order_value_w"] = df["order_value"].clip(lower=p01, upper=p99)
print(f"Max before Winsorizing: ₱{df['order_value'].max():,.0f}")
print(f"Max after  Winsorizing: ₱{df['order_value_w'].max():,.0f}")

Decision Framework: Remove, Winsorize, or Keep?

OUTLIER TREATMENT DECISION TREE
================================
Is the outlier a data entry error?
  YES → Remove the row (document the reason)
  NO  → Is it a legitimate extreme value?
          YES, analysis is descriptive → Winsorize (clip to 1st/99th percentile)
          YES, analysis is predictive  → Keep but flag with is_outlier=True column
          UNCERTAIN → Keep, report both with and without outliers

import pandas as pd
import re

df = pd.read_csv("shopflow_orders.csv")

Dtype Optimization & Downcast

The Three Rules of Tidy Data

1. Each variable forms its own column. 2. Each observation forms its own row. 3. Each type of observational unit forms its own table. Violations are the root cause of most "why won't this groupby work" bugs. Wide tables look clean in Excel but break analytics tools.

import pandas as pd

df = pd.read_csv("shopflow_orders.csv", parse_dates=["order_date"])

# --- Build a wide monthly-regional revenue table (untidy) ---
df["month"] = df["order_date"].dt.to_period("M").astype(str)
wide = (df.groupby(["month", "region"])["order_value"]
          .sum()
          .unstack("region")    # each region becomes a column
          .reset_index())
print(wide.head(3))
# month | Luzon | Visayas | Mindanao | NCR | ...

# --- Melt back to tidy: one row per month-region observation ---
tidy = wide.melt(id_vars="month",
                 var_name="region",
                 value_name="total_revenue")
print(tidy.head(6))
# month | region | total_revenue  ← correct tidy form

Choosing the Right Test

HYPOTHESIS TEST SELECTION
==========================
Two groups — numeric outcome
  Both normal? (n > 30 or normality test passes)
    Equal variance? → Student's t-test
    Unequal variance? → Welch's t-test  ← default choice
  Non-normal? → Mann-Whitney U test

3+ groups — numeric outcome
  Normal + equal variance? → One-way ANOVA
  Non-normal? → Kruskal-Wallis test
  Post-hoc (which pairs differ)? → Tukey HSD

Two categorical variables
  Expected frequency >= 5 in all cells? → Chi-square
  Any cell < 5? → Fisher's exact test

t-test, Effect Size, & Chi-Square

import pandas as pd
import numpy as np
from scipy import stats

df = pd.read_csv("shopflow_cleaned.csv")

# --- Business question: do express orders have higher value than standard? ---
express  = df[df["delivery_tier"] == "express"]["order_value"].dropna()
standard = df[df["delivery_tier"] == "standard"]["order_value"].dropna()

# Normality check first (Welch's t-test is robust even if violated for large n)
_, p_norm_exp = stats.normaltest(express.sample(min(500, len(express))))
_, p_norm_std = stats.normaltest(standard.sample(min(500, len(standard))))
print(f"Normality p: express={p_norm_exp:.3f}  standard={p_norm_std:.3f}")

# Welch's t-test (does not assume equal variances)
t_stat, p_val = stats.ttest_ind(express, standard, equal_var=False)
print(f"\nWelch t-test: t={t_stat:.3f}  p={p_val:.4f}")
print("Statistically significant at α=0.05" if p_val < 0.05 else "Not significant")

# Cohen's d — effect size (small: 0.2, medium: 0.5, large: 0.8)
pooled_std = np.sqrt((express.std()**2 + standard.std()**2) / 2)
cohens_d   = (express.mean() - standard.mean()) / pooled_std
print(f"Cohen's d: {cohens_d:.3f}  (effect size: {'large' if abs(cohens_d) >= 0.8 else 'medium' if abs(cohens_d) >= 0.5 else 'small'})")

# --- Chi-square: is delivery_tier independent of product_category? ---
contingency = pd.crosstab(df["product_category"], df["delivery_tier"])
chi2, p_chi, dof, expected = stats.chi2_contingency(contingency)
print(f"\nChi-square: χ²={chi2:.2f}  p={p_chi:.4f}  dof={dof}")

One-Way ANOVA & Post-Hoc Testing

import pandas as pd
from scipy import stats
from statsmodels.stats.multicomp import pairwise_tukeyhsd

df = pd.read_csv("shopflow_cleaned.csv")

groups = [
    df[df["delivery_tier"] == t]["order_value"].dropna()
    for t in ["standard", "express", "same_day"]
]

f_stat, p_anova = stats.f_oneway(*groups)
print(f"One-way ANOVA: F={f_stat:.3f}  p={p_anova:.4f}")

# Tukey HSD: which specific pairs differ?
tukey = pairwise_tukeyhsd(
    endog=df["order_value"].dropna(),
    groups=df.loc[df["order_value"].notna(), "delivery_tier"],
    alpha=0.05
)
print(tukey.summary())

Simple & Multiple OLS Regression

import pandas as pd
import numpy as np
import statsmodels.formula.api as smf
import matplotlib.pyplot as plt

df = pd.read_csv("shopflow_cleaned.csv").dropna(
    subset=["order_value", "quantity", "discount_pct", "shipping_fee"]
)

# --- Simple OLS: order_value ~ quantity ---
m1 = smf.ols("order_value ~ quantity", data=df).fit()
print(m1.summary().tables[1])   # coefficient table
print(f"\nR²: {m1.rsquared:.4f}")

# --- Multiple OLS with categorical (C() notation) ---
m2 = smf.ols(
    "order_value ~ quantity + discount_pct + shipping_fee + C(delivery_tier)",
    data=df
).fit()
print(f"R²: {m2.rsquared:.4f}   Adj R²: {m2.rsquared_adj:.4f}")
print(f"F-statistic: {m2.fvalue:.2f}  p: {m2.f_pvalue:.4e}")

# --- Residual diagnostics ---
fig, axes = plt.subplots(1, 2, figsize=(12, 4))

axes[0].set_ylabel("Residuals")

Spearman & Kendall Correlation

import pandas as pd
from scipy import stats

df = pd.read_csv("shopflow_cleaned.csv")

# Spearman: rank-based, robust to outliers and non-linearity
rho, p_spearman = stats.spearmanr(
    df["order_value"].dropna(), df["quantity"].dropna()
)

# Kendall: more conservative than Spearman for small samples
tau, p_kendall = stats.kendalltau(
    df["order_value"].dropna(), df["quantity"].dropna()
)

print(f"Pearson  r: {df['order_value'].corr(df['quantity']):.4f}")
print(f"Spearman ρ: {rho:.4f}  p={p_spearman:.4e}")
print(f"Kendall  τ: {tau:.4f}  p={p_kendall:.4e}")
